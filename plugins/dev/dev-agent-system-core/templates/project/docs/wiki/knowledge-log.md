# Knowledge Log — Errores Aprendidos (LE)

Formato de entrada (shorthand, ver .claude/_shorthand.md — !!prosa):

```
## LE-{INICIALES}-001: <título corto>
FP: <fingerprint exacto: patrón de error, forma de código o regex>
R: <causa raíz en una línea>
V: <verificación técnica que confirma el fix>
H: 0
v: {{DATE}}
```

Reglas: numeración secuencial por iniciales (Grep max → N+1) | H++ cada vez que se aplica | H>10 → ?PROMOTE a ST | H==0 + 30d → ?DELETE.
Índice compacto sincronizado en `.claude/rules/self-learning-error-prevention.md` (obligatorio).
